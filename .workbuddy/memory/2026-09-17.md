## 修复 `pnpm tauri build` 报错：A public key has been found, but no private key

**根因**：`src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey` 是模板占位符
`YOUR_UPDATER_PUBKEY_HERE`（**非空字符串**）。Tauri CLI 只要看到 pubkey 非空，
就认定要做更新包签名，强制要求 `TAURI_SIGNING_PRIVATE_KEY`；而本项目从未生成过
签名密钥对（`docs/development-guide.md:38` 记载 project-init 本应生成第 7 步，实际漏做）。
`bundle.createUpdaterArtifacts: "v1Compatible"` 进一步要求产出 `.sig`。

**修复内容**：
- 生成密钥对：`pnpm tauri signer generate -w src-tauri/keys/opsentr.key -p <随机28位> --ci -f`
  - 私钥 `src-tauri/keys/opsentr.key`、公钥 `.key.pub`、密码 `.key.password`
  - `src-tauri/keys/` 已被 .gitignore 忽略（模板第 36-37 行原有约定，无需新增规则）
- `tauri.conf.json` 的 `pubkey` 填为真实公钥（generate 输出的 base64）

**关键踩坑（Tauri v2 updater 签名，跨项目可复用）**：
1. **`.env` 文件完全无效** —— 官方文档明确写「.env 文件不起作用」，CLI 不加载 dotenv，
   必须用真实系统/会话环境变量。已实测：项目根写 `.env` 后构建仍报同样错。
2. **`build` 命令只认 `TAURI_SIGNING_PRIVATE_KEY`**，不认 `TAURI_SIGNING_PRIVATE_KEY_PATH`。
   只设 `_PATH` 会照样报 "no private key"。（`signer sign` 子命令则两个都认，行为不一致）
3. **无密码私钥在 Windows 上不可用**：CLI 发现密码变量不存在时会交互式提示 `Password:`，
   从 tty 读取；在 IDE/非交互环境会永久挂起（现象：构建停在 `Finished 1 bundle at:` 之后，
   既不报错也不产出 .sig）。而 Windows 无法设置空字符串环境变量（设空 = 删除变量），
   所以**必须给私钥设真实密码**。
4. 两个变量都必须提供且非空：
   - `TAURI_SIGNING_PRIVATE_KEY` = 私钥内容（或文件路径）
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` = 私钥密码

**验证**：`pnpm tauri build --debug` → `Finished 2 updater signatures at:`，
产出 `setup.exe.sig` + `setup.nsis.zip.sig`，EXIT=0。

**附带观察**：构建有既有警告 `struct AlertRule is never constructed`（models/mod.rs:85，非本次引入）；
另有提示 `Legacy v1 compatible updater is deprecated ... change createUpdaterArtifacts to true`（v3 将移除，后续可迁移）。

**已落地**：
- 本机**用户级环境变量**已写入 `TAURI_SIGNING_PRIVATE_KEY`（私钥内容）+ `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
  （用 `[Environment]::SetEnvironmentVariable(..., "User")`；当前已开着的 IDE 需重启才能继承）
- `.github/workflows/release.yml` 的密码字段已从写死的 `''` 改为
  `${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}` —— **用户需在 GitHub Secrets 补配该密码**，
  否则 CI 构建会失败（有密码的私钥必须提供密码）
- `docs/development-guide.md` 已补「生产构建需要签名环境变量」说明
- 密钥文件：`src-tauri/keys/{opsentr.key, opsentr.key.pub, opsentr.key.password}`
  （密码是生成的 28 位随机串，用户可自行更换：重新 generate 后同步更新 pubkey 与两个环境变量）
- **最终验证**：从用户级环境变量读取 → `pnpm tauri build --debug` → `Finished 2 updater signatures at:`，
  产出 `setup.exe.sig` + `setup.nsis.zip.sig`，EXIT=0
- 仍未提交 git
