# 头脑风暴框架

## 本项目技术约束

> 所有方案必须在以下技术栈约束内思考

### 技术边界

- **后端**: Rust 2021 edition + Tauri 2.x（不是 Java/Python/Node.js）
- **前端**: React 19 + TypeScript 5.8 + Vite 7（不是 Vue/Angular）
- **通信**: Tauri IPC `invoke()` / `listen()`（不是 HTTP REST API）
- **安全**: Capabilities 权限声明（不是 RBAC/JWT）
- **数据存储**: 本地文件 / SQLite（不是 MySQL/PostgreSQL 服务器）
- **部署**: 桌面安装包 .exe/.dmg/.deb（不是服务器部署）
- **依赖管理**: Cargo (Rust) + pnpm (Node.js)

---

## 思维模式

### 发散思维
1. **不评判**: 先不考虑可行性
2. **联想**: 从一个想法延伸
3. **Rust 生态**: 能否用现有 crate 解决？
4. **Tauri 插件**: 有没有现成的插件？
5. **跨界借鉴**: Electron/Flutter 怎么做的？
6. **反向思考**: 反过来就是解决方案

### 收敛思维
1. **复用优先**: 能否复用现有 crate 或 npm 包？
2. **可行性**: 在 Rust + React 技术栈内能否实现？
3. **前后端分工**: 这个逻辑应该放在 Rust 侧还是 React 侧？
4. **权限**: 是否需要声明额外的 Capabilities？
5. **成本**: 开发时间和复杂度
6. **跨平台**: 方案在 Windows/macOS/Linux 上是否都能工作？
